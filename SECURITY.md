# Security Policy

## Supported versions

The site is continuously deployed from `main`. There is only ever one version in
the wild, so fixes land immediately.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security problem.

Contact the guild owner privately: send a Discord direct message to **@tajious**
via the Timeless Circle server, and include:

- what the issue is
- how to reproduce it
- the impact you believe it has

You will get an acknowledgement, and a fix or a decision on next steps. If the
Discord route is not an option for you, open a regular issue that only describes
the concern without proof-of-concept detail and ask for a private channel.

## Scope

This repository holds the public landing page: static HTML, CSS, JavaScript and
the Nginx configuration. Issues with the Discord server itself are out of scope
and belong with Discord directly.
